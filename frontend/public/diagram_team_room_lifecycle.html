별지 제 2호

팀 모집(팀룸) 라이프사이클 무결성 & 상호 실시간 알림 시스템

S5-2 TeamRoom Lifecycle State Machine (지원, 탈퇴, 강퇴, 수정, 삭제) & Realtime Push

Bidirectional State Machine

공매치 풀스택 플랫폼 (정성원)

STATE 1. [OPEN] 모집 진행 상태 status = "OPEN"

• 누구나 잔여 TO가 있는 직무에 자유롭게 지원 가능

• 직무 지원 발생 시: currentCount += 1

• 모든 직무 정원(TO) 100% 충족 시 ➔ CLOSED 자동 전이

✓ 실시간 알림 발송: 방장에게 [🎉 {지원자}님이 합류했습니다!] 전달
STATE 2. [CLOSED] 모집 마감 상태 status = "CLOSED"

• 추가 지원 원천 차단 및 소속 팀원에게 오픈채팅 링크 개방

• 지원 취소(탈퇴) 또는 강퇴 발생 시: currentCount -= 1

• 결원 발생 즉시 모집 재개를 위해 ➔ OPEN 자동 역전이

✓ 실시간 알림 발송: 방장에게 [👋 {학생} 탈퇴] 또는 학생에게 [⚠️ 제외] 전달

🔔 5대 전방위 상호 실시간 알림(Notification) 이벤트 매핑 명세

🎉 팀원 합류
수신: 방장

"{학생}님이 [{방제목}] 팀룸에 합류했습니다!"

👋 지원 취소/탈퇴
수신: 방장

"{학생}님이 지원을 취소(탈퇴)했습니다. (TO 복원)"

⚠️ 팀원 강퇴
수신: 대상 학생

"[{방제목}] 팀룸에서 제외되었습니다."

✏️ 방 정보 수정
수신: 팀원 전원

"[{방제목}] 모집 요강 또는 링크가 수정되었습니다."

🗑️ 팀룸 삭제/해산
수신: 팀원 전원

"[{방제목}] 팀룸이 방장에 의해 삭제되었습니다."
