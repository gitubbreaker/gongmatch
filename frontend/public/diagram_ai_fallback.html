Dual-Safety Architecture

공매치 풀스택 플랫폼 (정성원)

🤖 S4 공모전 AI 4대 핵심 분석 리포트

AiParsingService
1. 실시간 GPT-4o-mini 분석 (Primary)

크롤링 본문 원문을 전달하여 features, studyMethod, judgingCriteria, pastInsights 4개 필드 실시간 JSON 파싱

2. 스마트 도메인 룰 Fallback (Secondary)

외부 API 네트워크 타임아웃 또는 토큰 소진(429) 시, 대회 도메인(AI/데이터, 해커톤/SW, 비즈니스/창업)을 자동 판별하여 고품질 전문 리포트 즉각 생성

3. 프론트엔드 동적 Fallback (Final Safety)

DB 구버전 캐시 데이터가 오더라도 useMemo가 작동하여 빈 화면 없이 100% 리포트 항시 노출 보장

💬 S8 팀룸 카카오톡 AI 요약 (AiSummaryService)

KST Calendar Injection
1. 한국 표준시(KST) 1년 달력 동적 주입

"이번 주 금요일", "다음 주 수요일" 등 상대적 표현의 환각(Hallucination) 방지를 위해 백엔드에서 1년치 요일 달력을 프롬프트에 동적 결합

2. 멀티 안건(Topic) 및 팀원 역할 격리 추출

대화 속 여러 안건을 독립 JSON 배열로 분리하고, 장소 정보가 누락되었을 경우 유추하지 않고 확실히 '미정'으로 처리하는 무결성 보장

3. 로컬 정규식 파서 백업 (Local Parser)

네트워크 장애 발생 시에도 대화 내 [이름], 일정 키워드, 역할 키워드를 로컬 정규식 엔진이 자동 파싱하여 반환

{ "topics": [{ "title": "캡스톤 발표", "schedule": "10월 14일 15시", "location": "강남 스터디룸", "roles": [...] }] }
